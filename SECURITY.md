# Security policy

## Supported versions

Security fixes are prepared for the current private release-candidate branch. No public
release is supported yet.

## Reporting a vulnerability

Report vulnerabilities privately to `security@seminai.tech`. Do not open a public issue and
do not include user data, production credentials, database dumps, or customer documents.
Include the affected commit, a minimal synthetic reproduction, impact, and suggested fix.

You should receive an acknowledgement within five business days. Coordinated disclosure
timing is agreed after triage. This policy does not authorize access to third-party systems,
destructive testing, denial of service, social engineering, or handling real user datasets.
