# Contributing

1. Branch from the current default branch and keep each change focused.
2. Use Node.js 22 and the root npm lockfile.
3. Keep code and documentation in English, files at or below 300 lines, and TypeScript free
   of explicit `any`.
4. Never commit user/customer data, secrets, local environment files, dumps, generated
   clients, runtime state, or test artifacts.
5. Run `npm run gate` before requesting review.
6. Sign every commit according to [`DCO.md`](./DCO.md).

Contributions are accepted under AGPL-3.0-or-later and the commercial-relicensing grant
described in `DCO.md`. Do not submit work you are not entitled to license on those terms.
